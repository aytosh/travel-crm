# Travel CRM

CRM-система для туристического агентства. Веб-приложение на **Next.js 16 (App Router) + TypeScript + Prisma + Tailwind CSS**. Работает в браузере на телефоне, планшете и компьютере. Интерфейс на русском языке.

## Возможности (реализовано)

- **Авторизация** по логину и паролю, сессии в httpOnly cookie, роли **Владелец** и **Сотрудник** с разграничением доступа.
- **Главная панель владельца** — показатели за период (сегодня / вчера / неделя / месяц / год / произвольный период): получено денег, новые продажи, продано туров, новые клиенты, доплаты, долги клиентов, долги партнёрам, прибыль, расходы. Каждый показатель кликабелен и ведёт в детализацию.
- **Клиенты** — общая база, поиск, карточка с историей покупок/платежей, суммой покупок и текущим долгом, проверка дубля телефона при создании.
- **Продажи** — создание продажи со всеми полями ТЗ, автоматический расчёт прибыли, карточка с полной стоимостью, оплатами, остатком долга, продавцом и партнёром.
- **Платежи** — несколько платежей на одну продажу, способы оплаты (наличные / банк / карта / QR). **Продавец и получатель денег учитываются раздельно. Доплата не создаёт новую продажу.**
- **Партнёры** — карточка с задолженностью, историей переводов, бронированиями и сроком оплаты; частичная и полная оплата партнёру. Долг партнёру создаётся автоматически из закупочной стоимости.
- **Долги клиентов / Долги партнёрам** — отдельные списки обязательств.
- **Финансы** — валовая/чистая прибыль, долги, расходы (по формулам ТЗ).
- **Расходы** — категории, валюта, дата, комментарий (владелец).
- **Сотрудники** — создание, назначение логина/пароля, блокировка/разблокировка, сброс пароля, статистика (владелец).
- **Отчёты** — ежедневный свод + разбивка по сотрудникам (продажи, поступления, лично принято, доплаты, прибыль).
- **Настройки** — название агентства, основная валюта отчётности.
- **Мультивалютность** — USD / VND / EUR (расширяемо); у каждой операции хранится валюта и курс к базовой.
- **Журнал изменений** (audit log) пишется при ключевых операциях.

### В планах (каркас готов, наполняется)
Авиабилеты (ручной ввод, статусы, PDF), Календарь поездок и сроков, Финансовый прогноз, дашборд сроков оплат партнёрам, просмотр журнала изменений в UI.

## Запуск (разработка)

Требуется Node.js 18+ (проверено на Node 24).

```bash
npm install
npx prisma migrate dev   # создаёт базу SQLite dev.db
npm run db:seed          # демо-данные + учётные записи
npm run dev              # http://localhost:3000
```

### Демо-доступы
- Владелец: `owner` / `owner123`
- Сотрудник: `manager` / `manager123`

> После первого входа смените пароли (раздел «Сотрудники» → «Сбросить пароль»).

## Полезные команды

| Команда | Назначение |
|---|---|
| `npm run dev` | Запуск в режиме разработки |
| `npm run build` / `npm start` | Продакшн-сборка и запуск |
| `npm run db:seed` | Заполнить базу демо-данными |
| `npm run db:studio` | Prisma Studio (просмотр БД в браузере) |
| `npm run db:reset` | Сбросить и пересоздать базу |

## Переход на PostgreSQL (продакшн)

1. В `prisma/schema.prisma` поменяйте провайдер:
   ```prisma
   datasource db {
     provider = "postgresql"
     url      = env("DATABASE_URL")
   }
   ```
2. В `.env` укажите строку подключения:
   ```
   DATABASE_URL="postgresql://user:password@host:5432/travel_crm?schema=public"
   ```
3. Сгенерируйте и примените миграции:
   ```bash
   npx prisma migrate deploy   # или: npx prisma migrate dev --name init
   npm run db:seed
   ```

## Безопасность и эксплуатация

- Обязательно задайте надёжный `SESSION_SECRET` в `.env` (длинная случайная строка).
- Пароли хранятся как bcrypt-хеши.
- Для продакшна используйте HTTPS (например, за reverse-proxy nginx/Caddy) — куки сессии помечаются `secure` в production.
- Настройте регулярное резервное копирование базы данных.

## Стек

- Next.js 16 (App Router, Server Actions), React 19, TypeScript
- Prisma ORM (SQLite в dev, PostgreSQL в проде)
- Tailwind CSS v4
- Авторизация: `jose` (JWT в cookie) + `bcryptjs`
